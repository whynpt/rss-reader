# Streamline RSS 界面设计

## 设计方向

把“视频优先的暗色网格”改为安静的个人内容收件箱。文章、视频和播客共享时间信息流、收藏与阅读状态，同时保留各自需要的内容结构。

纸白背景、墨色文字和单一陶土强调色构成视觉底色。中文宋体用于内容标题，无衬线用于导航、摘要与控件。强调色主要用于品牌标识及添加订阅，不用不同颜色区分内容类型。

桌面采用固定宽度的左侧订阅导航与受约束的信息流。详情在右侧展开，手机切换为全宽详情和可打开的订阅抽屉。没有营销 hero、推荐算法或虚构指标。

## 原界面的审查与改版

依据提供的架构与功能摘要进行设计，不读取或修改原 React 源码。

| 原设计倾向 | 改版处理 |
| --- | --- |
| 视频优先、暗色网格 | 以阅读为主的浅色时间信息流；深色仅用于视频观看舞台 |
| 三类内容呈现趋同 | 文章强调文字，视频强调16:9封面，播客强调方形封面与集数 |
| 点击后主要依赖单一详情 | 按 `media_type` 分为阅读、观看、收听三种详情 |
| 播放状态容易随详情卸载 | 播客播放器独立于详情，保留播放状态与进度 |
| 状态反馈不够明确 | 增加筛选空状态、添加校验、刷新骨架、本地保存失败提示 |
| 手机导航空间不足 | 提供订阅抽屉，类别标签始终可见 |

保留订阅、未读计数、搜索、刷新、收藏、阅读状态、文章全文、视频清晰度、B站账号入口及播客时间点的操作位置。

照片是环境演示素材，不冒充真实知乎文章或B站视频封面。播客封面为内联原创排版，明确标注“演示节目”。阅读照片显示完整画面；视频封面与舞台有意裁成16:9，服务媒体类型识别。

## 关键流程

### 浏览、筛选与搜索

1. 默认显示六条完整演示内容，文章、视频、播客各两条。
2. 侧栏切换收件箱、未读、收藏或单个订阅。
3. 顶部切换全部、文章、视频、播客。
4. 搜索同时匹配标题、摘要、作者和订阅名称。
5. 侧栏范围、类别和搜索共同生效；类别计数基于当前范围与搜索。
6. “全部已读”只作用于当前筛选结果，不修改其他范围。

搜索输入限制200字符，内容使用 HTML 转义。无结果时显示查询词与清空操作。

### 收藏与未读

星标可直接切换收藏，收藏页即时更新。阅读状态按钮支持标为已读或未读。打开详情即标为已读，侧栏计数同步变化。

演示收藏、阅读状态和新增订阅存储在专用键 `streamline:prototype:v1`。存储失败时保留当前操作，并提示无法跨页面关闭保存。没有访问真实数据库或凭证。

### 文章详情

文章使用宋体标题、较宽松的中文行距与受约束的正文宽度。两篇文稿具有完整段落、分节标题和结尾说明，均标注为原创演示内容。

关闭按钮、遮罩和 Escape 均可返回信息流。关闭后恢复内容入口焦点；如果入口因筛选消失，则恢复主区焦点。

### 视频详情

深色16:9舞台展示本地海岸封面，支持演示播放、暂停与进度拖动。

清晰度选项保留1080P与720P。提示始终区分：
- 用户选择的目标清晰度；
- 演示设定的返回档位720P；
- 未获取的实际清晰度。

没有真实视频流、B站访问或登录，计时变化不代表1080P播放成功。关闭或切换详情时停止视频演示。

### 播客详情与持续收听

方形节目封面、集数、主播、时长与 Show Notes 组成详情。时间点可直接启动收听并定位进度。

底部播放器独立于详情，支持播放、暂停、进度拖动、速度选择，以及桌面15秒前后跳转。打开文章或关闭播客详情，播放器继续存在。

手机保留标题、播放按钮、拖动进度与速度，隐藏15秒按钮以控制密度。点击播放器标题可重新打开对应详情。

视频开始演示时暂停播客，播客开始演示时暂停视频，避免两个模拟计时器同时处于播放状态。播放器仍保留播客进度。

### 添加订阅

名称可选，地址必填。来源类型涵盖知乎/文章、B站视频、播客。

地址在失焦与提交时校验：
- 必须是完整 HTTP / HTTPS 地址；
- 地址需含有效形式的域名；
- 不接受内嵌账号密码；
- 不接受重复地址。

错误保留输入并显示文字说明。提交进入短暂等待状态，阻止重复提交。“填入示例来源”使用保留的 `example.com` 域名，不请求该地址。

新增订阅初始为空，可通过“放入一条演示内容”查看对应类型的后续流程。该内容明确属于本地演示，不表示订阅抓取成功。

### B站账号与关注入口

“订阅与账号”保留扫码登录和导入关注入口：
- 扫码入口解释真实产品的登录位置，不伪造二维码或登录成功；
- 导入入口加入一份明确标注的本地演示关注；
- 不读取实际账号、Cookie、凭证或关注列表。

| 用途 | token / 值 |
| --- | --- |
| 页面背景 | `--bg: #f8f6f1` |
| 内容表面 | `--surface: oklch(99% .006 85)` |
| 正文墨色 | `--fg: #252620` |
| 次要文字 | `--muted: oklch(47% .018 85)` |
| 分隔线 | `--border: oklch(85% .016 85)` |
| 单一强调色 | `--accent: #a64e36` |
| 强调色 hover | `--accent-hover: oklch(43% .11 37)` |
| 轻背景 | `--soft: oklch(94% .014 85)` |
| 当前导航背景 | `--selected: oklch(91% .021 85)` |
| 校验错误 | `--danger: oklch(43% .15 28)` |
| 视频舞台 | `--stage: oklch(20% .012 85)` |
| 视频舞台文字 | `--stage-fg: oklch(96% .008 85)` |
| 标题字体 | Songti SC / Noto Serif CJK SC / STSong / Georgia / serif |
| 正文字体 | PingFang SC / Microsoft YaHei / Noto Sans CJK SC / sans-serif |

字号以12、13、15、18、23、28、32px为主要层级。阅读正文17px；手机16px。详情标题响应式26—34px。中文标题行高至少1.4，阅读正文1.95，不使用负字距。

间距基础为4px，主要层级为4、8、12、16、24、32、48px。桌面侧栏242px，主区最大1000px，详情最大850px。响应式在1024px收紧，在767px切换移动导航。

控件目标通常至少44px。焦点采用墨色轮廓；hover改变背景，不降低文字对比。减少动态效果的系统偏好会关闭动画与过渡。

## 状态与后端接入建议

### 类型筛选

增加组合筛选状态：

`scope + selectedFeedId + mediaType + searchQuery`

列表从同一数据集派生，不为三种类型维护三份互相不同步的数据。`media_type` 统一归一为 `article / video / podcast`；缺失值需有确定的兼容规则。

正式接入分页时，应让后端按同一组合条件返回列表与计数，避免当前页计数误当全量计数。若现有接口已支持类型过滤，则复用；否则增加可选过滤参数与 SQLite 查询条件。

### 持续收听

将真实音频元素与状态提升到 `App` 或全局播放 Provider，避免详情关闭时卸载：

`activeEntryId + currentTime + duration + playbackStatus + playbackRate + mediaError`

原型用独立 `audio` 状态和计时器证明该结构。正式实现需监听真实媒体事件，计时、缓冲与结束以音频元素为准。

持续播放本身通常不需要新增后端接口。如果要增加跨设备进度、持久化收听队列或历史记录，再引入相应存储与接口；这些能力不属于本次原型。

### 视频清晰度

分别维护请求清晰度与实际返回清晰度。后端流解析需返回可核验的档位或分辨率；前端不能用选择框值代替实际信息。

保留现有1080P/720P解析、鉴权失败和B站扫码登录流程。本原型的720P是固定演示档位，不能直接迁移为生产逻辑。

### 字段适配

现有核心字段保持：
`id, title, feed_title, feed_source, media_type, summary, content, thumbnail, duration, published_at, is_read, is_starred`

原型额外使用：
- `feed_id`：关联订阅筛选，正式接入采用已有订阅关联字段。
- `author`：作者、UP主或主播；正式接入需确认解析结果，不存在时省略。
- `episode`：节目集数；缺失时不显示。
- `content`：真实阅读正文应通过已有全文能力加载并进行安全清洗。
- Show Notes：迁移现有音频详情解析结果，不把原型固定章节当真实节目数据。

知乎订阅地址格式与解析能力尚未确认。表单接受地址不等于后端已支持知乎订阅。

## 状态与可访问性

- 正常状态：六条内容及三种完整详情。
- 等待状态：刷新显示信息流骨架；添加订阅锁定控件并显示等待文字。
- 空状态：收藏为空、未读清空、搜索无结果、新订阅无内容。
- 错误状态：地址格式错误、重复订阅、本地存储读取/写入失败。
- 边界处理：长标题换行、名称与查询长度限制、缺少封面的文章使用纯文字结构。
- 详情和手机抽屉打开后，背景区域设置为 inert。
- 详情与抽屉提供键盘焦点循环；添加和账号窗口使用原生 dialog。
- 状态消息使用预先存在的 live region。
- 提示不自动消失，用户可主动关闭。
- Escape 关闭当前详情、抽屉或原生对话框。
- `/` 快捷键聚焦搜索，输入字段内不会触发。
- 三类内容不只靠颜色辨识，也提供图标、文字、尺寸与结构。
