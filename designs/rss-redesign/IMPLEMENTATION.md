# 第一版实现与验收

实际应用入口：`http://localhost:5173/`。本目录的 `index.html` 保留为设计原型，运行界面由 `src/` 的 React 组件实现。

## 已实现

- 暖白纸张、衬线标题、订阅侧栏与时间流，桌面和手机布局。
- 文章 / 视频 / 播客筛选，与订阅、分类、未读、收藏、搜索组合使用。计数查询覆盖全部结果，每页加载 60 条。
- 文章阅读面板与原有全文提取；B站原生播放、1080P / 720P 选择和实际清晰度提示；保留 YouTube 嵌入及备用取流。
- 底部持续播客播放器：关闭详情或切换阅读时继续收听，支持进度、前后 15 秒、倍速、Show Notes 章节；播放视频和播客时互相暂停。
- 添加订阅、名称与分类、地址校验，以及原有 B站扫码登录和关注导入。
- 加载、空内容、无搜索结果、请求失败、播放器错误与操作反馈；键盘导航、弹窗焦点、Escape 关闭。
- 后端统一查询、计数与批量已读条件，避免搜索、类型或分页导致批量操作范围扩大；前端拒绝过期筛选请求。

## 验收

- `npm test`：8 个用例，覆盖类型组合、作者搜索、超过 60 条的计数与分页、批量已读范围、SQL 参数绑定和 B站联合投稿名称归属。
- `npm run build`：生产构建通过。
- 实际应用通过现有订阅数据验收；文章、播客及收藏 / 已读操作在独立临时数据库中验证，测试数据不随仓库发布。
- 真实公开音源验证播放成功，实际时长约 97 秒；章节定位、1.5 倍速、快进、暂停，以及文章阅读时继续播放正常。
- B站匿名测试返回 1280 × 720 视频，切换 1080P / 720P 时保留进度且页面留在本站；界面如实提示账号权限及实际返回质量。
- 已登录场景下实际返回 720P 时，界面不会将所选的 1080P 误报为实际分辨率；验收时浏览器未出现控制台错误。
- 手机 390 × 844 下验收订阅抽屉、全宽阅读与迷你播放器，页面没有横向溢出。
- 搜索正向结果与空结果、收藏与取消收藏、批量已读、订阅地址报错和 Escape 关闭均通过界面验证。

## 当前边界

- 知乎热榜沿用现有解析；其他知乎内容需提供可用的 RSS 源。
- 播客进度在页面会话中保留，刷新或重新打开后的恢复尚未实现。
- B站 1080P 取决于平台、视频格式与账号权限；YouTube 仍依赖网络和本机已有的取流能力。
- 第一版保持原有数据库结构、订阅数据与登录机制。
